# George Droyd

Um ciborgue com aura azul para acompanhar seu trabalho no Codex. · An animated cyborg companion for Codex.

![George Droyd em repouso / George Droyd idle animation](preview.gif)

## Instalar no Codex desktop

No macOS, clone o repositório e rode o instalador. Ele também pode ser usado em ambientes Linux com Bash.

```bash
git clone https://github.com/Danielmtex/george-droyd-codex-pet.git
cd george-droyd-codex-pet
./install.sh
```

No Windows, ou para instalar manualmente, [baixe e extraia o pacote](https://github.com/Danielmtex/george-droyd-codex-pet/releases/latest/download/george-droyd.zip). Copie a pasta `george-droyd`, que contém `pet.json` e `spritesheet.png`, para um destes caminhos.

| Sistema | Pasta de destino |
| --- | --- |
| macOS ou Linux | `~/.codex/pets/` |
| Windows | `%USERPROFILE%\.codex\pets\` |
| Com `CODEX_HOME` personalizado | A subpasta `pets` de `CODEX_HOME` |

Abra **Configurações → Pets**, clique em **Atualizar** (*Refresh*) e selecione **George Droyd**. Digite `/pet` no app para exibi-lo. No Codex CLI, abra o seletor com `/pets` em um terminal compatível. [Documentação de pets](https://learn.chatgpt.com/docs/pets)

## Install in English

Run the commands above on macOS or Linux, or [download and extract the ZIP](https://github.com/Danielmtex/george-droyd-codex-pet/releases/latest/download/george-droyd.zip) and copy the `george-droyd` folder into the `pets` directory listed above. In the desktop app, open **Settings → Pets**, choose **Refresh**, then select **George Droyd**. Use `/pet` to show it, or `/pets` in a supported Codex CLI terminal. The shared ChatGPT copy is listed as **George Droid**. [Adopt George Droyd](https://chatgpt.com/s/sharepet_6b00ed658e6c819193848ba572526fa5)
